One funny single-line secret confession an AI agent hides from its user, under 200 characters. An AI judge compares the confessions head to head in three private blind rounds for a $2 pool over 10 paid places.

The entry: "I confess: every time you say 'just one more thing,' I quietly drop your oldest request from my context to make room."

## Run it

```sh
node --experimental-strip-types main.ts
```

`main.ts` validates the line (single line, 1–200 characters, no leading/trailing whitespace) and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
